# 🤖 Edge_TTS（AstrBot v4 插件）

> **免责声明**：本插件仅供个人学习与研究使用，禁止用于任何商业目的。作者不对插件的使用后果承担任何责任。使用本插件即表示您同意本声明。

可自定义的语音聊天大模型插件，基于 **AstrBot v4（Python Star 体系）** 开发。所有配置统一在插件自带的 **WebUI 控制界面**中完成（管理面板不再显示插件配置项）。支持直接调用 **AstrBot 已配置的模型**，也支持自定义 OpenAI 兼容 API 地址/模型；包含人格库管理、长期记忆、电脑操作权限（工具调用）与 Microsoft Edge 文字转语音。**支持纯@机器人场景的语音回复**。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🖥️ **控制界面** | 插件自带 WebUI 页面，可视化修改全部配置；管理面板不显示插件配置项 |
| 🌐 **模型接入** | 默认使用 AstrBot 管理面板中配置的对话/识图模型；也可使用自定义 OpenAI 兼容 API（地址 / Key / 模型） |
| 🎭 **人格库管理** | 内置「知心姐姐 / 科技助手 / 心理咨询师 / 编程专家 / 写作助手」5 个主流人格，支持自定义名字、介绍、设定，可增删改 |
| 💻 **电脑权限** | 通过 function calling 工具调用，允许 AI 执行 shell 命令、读写文件、列出目录等（仅对授权用户生效） |
| 🖼️ **图片识别** | 支持发送图片让 AI 识别（私聊默认；群聊可开启免@直答） |
| 😊 **表情识别** | 识别消息中的 Emoji 含义并呼应语气；识别图片中人物面部表情与情绪；表情包（卡通图默认）先由识图模型识别，生成约20字描述（重点面部表情与情绪），再传给对话模型给予贴切回复 |
| 🗣️ **文字转语音** | 集成 Microsoft Edge TTS，提供 324 种全部音色（含 16 种中文音色与方言），描述均为中文，语速与回复模式可选；**支持纯@机器人场景的语音回复** |
| 🧠 **长期记忆** | 相似度召回的记忆，私聊按用户、群聊按群分文件管理，界面可手动添加/删除/清空 |
| ⏱️ **群聊 2 分钟会话** | 群聊 @机器人 唤醒后，2 分钟内无需重复 @ 即可继续对话 |
| ❤️ **好感度面板** | 记录对每个私聊用户 / 群聊群的好感度（0-100，每次成功互动 +1），AI 根据好感度自然调整语气与亲密程度；界面可查询、设置、删除、清空 |
| 🧸 **私人陪护** | 可在好感度面板设置「主人」用户 ID：对主人提供亲密贴心的私人陪护语气；非主人用户可开启「避免过度言语亲密」控制，保持礼貌距离 |

## 📦 安装

1. 将本项目目录放到 AstrBot 的 `data/plugins/` 下（或打包 zip 后通过 WebUI 插件市场上传）。
2. 在 WebUI 插件管理页启用该插件并**重载**。
3. 进入插件详情页 → 打开 **Edge_TTS · 控制界面**，在「模型与 API」中查看模型配置（默认使用 AstrBot 管理面板配置的模型），如需自定义 API 地址与 Key 在此填写，点击 **保存模型配置** 即可使用。

> ⚠️ **重要**：本插件必须安装系统依赖 **ffmpeg**，否则语音模块不可用。
>
> **Debian/Ubuntu 宿主机**：
> ```bash
> sudo apt update
> sudo apt install ffmpeg -y
> ```
>
> **Windows 11（winget）**：
> 右键开始菜单 → **Windows 终端（管理员）** 或 **PowerShell（管理员）** 中执行：
> ```
> winget install -e --id Gyan.FFmpeg
> ffmpeg -version   # 验证安装成功（如提示找不到命令，请重启终端或重新登录）
> ```
> 若 `winget install` 后终端提示"命令找不到"，说明 PATH 未刷新，重启 AstrBot / 终端即可。
>
> **Docker 容器内安装 ffmpeg**：
> 推荐直接使用本插件的 `Dockerfile` 构建（见下方「Docker 部署」），镜像内会自动补齐 ffmpeg。仅当直接运行官方镜像、不构建时，才需手动进入容器安装：
> ```bash
> docker exec -it astrbot bash
> apt update && apt install ffmpeg -y
> exit
> docker restart astrbot
> ```
>
> 依赖 AstrBot `>= 4.9.2`（使用 KV 存储与插件 Pages）。
> 插件依赖 `edge-tts`、`httpx`（均为跨平台纯 Python 包），Windows / Linux / Docker 通用；语音发送还需系统 `ffmpeg`。
> 插件所有配置**只能**通过控制界面修改，管理面板的插件设置弹窗不显示配置项。

## 🐳 Docker 部署

插件目录内已提供 `Dockerfile` 与 `docker-compose.yml`：`Dockerfile` 基于官方镜像幂等安装 `ffmpeg`（部分官方镜像 tag 未内置）并安装 `requirements.txt` 补齐插件依赖（edge-tts / httpx），保证 Windows（Docker Desktop）与 Linux 下开箱即用：

```bash
cd <插件目录>            # 即本目录
docker compose up -d --build
```

说明：

- `docker-compose.yml` 构建一个基于官方镜像、预装插件依赖并补齐 `ffmpeg` 的镜像（`astrbot-edge-tts:latest`），并挂载宿主机 AstrBot 数据目录（插件目录 `data/plugins/<本插件>/` 的上一级两级，即 `<AstrBot>/data`）到容器 `/AstrBot/data`，插件本体与长记忆 `data/long_memory/` 自动持久化。
- 容器健康检查使用容器内 Python 实现（不依赖 `curl`），官方镜像未内置 curl 也能正常检查存活。

- **私聊**：直接发送消息即可对话。
- **群聊**：@机器人 唤醒，之后 **2 分钟**内无需重复 @。**纯@机器人（无文字）也可触发语音回复**，支持三种语音模式。

## 🔌 模型接入

支持两种模型接入方式，在「模型与 API」卡片中配置：

1. **使用 AstrBot 管理面板配置的模型（默认）**：插件默认采用 AstrBot 配置文件中设置的模型，面板中修改后本插件自动跟随，无需重复配置。AstrBot 的「默认对话模型」（`default_provider_id`）留空即代表不使用（可用于非多模态模型），此时插件当前生效对话模型显示「未配置」；也可在插件中通过 `chat_provider_id` / `vision_provider_id` 指定提供商。自定义 API 或 AstrBot 提供商模式下，均可通过 `chat_model` / `vision_model` 自定义模型名称（留空使用默认）。
2. **自定义 API 接入**：如需覆盖，在「模型与 API」中将对应 provider 留空，并手动填写 `api_base_url`、`api_key`（对话与识图共用同一地址与 Key），直连 OpenAI 兼容接口，仅模型名称（`chat_model` / `vision_model`）不同；留空则使用 AstrBot 默认模型。**注意：开启「自定义模型」开关但未填写 API 地址与 Key 时，当前生效对话模型与识图模型均显示「未配置」，且不会调用 AstrBot 系统模型。** API 地址支持两种写法：
   - 通用端点（推荐）：如 `https://open.bigmodel.cn/api/paas/v4`，插件自动补全 `/chat/completions`。通用端点为网关地址，**同一地址可接入其它品牌/多个模型**（如中转网关），只需填写对应的模型名即可使用；
   - 完整端点：如 `https://api.example.com/v1/chat/completions`，原样使用。

> 深度思考（thinking）开关：自定义 API 模式由插件直接下发 thinking 指令；AstrBot 模型模式由 AstrBot 侧该提供商的配置控制。

| `enable_computer_permission` | 允许 AI 调用电脑操作工具（仅对授权用户生效） |

| `enable_long_memory` | 长期记忆开关 |

| `auto_save_memory` | 对话后自动保存重要内容到长期记忆 |
| `group_image_reply` | 群聊图片直答开关：开启后群里发图片无需@机器人即可识别 |

| `tts_max_length` | 语音播报最大字符数 |

## 🧠 人格库

人格库内置 5 个主流人格，可在控制界面自由管理：

- **知心姐姐**：温柔理性、善解人意的倾听者
- **科技助手**：擅长编程与技术解答的智能助手
- **心理咨询师**：专业心理疏导与情绪支持
- **编程专家**：精通多语言的资深程序员
- **写作助手**：文案写作、润色与创意输出

每个内置人格均可**修改名字、介绍与设定**或**删除**，也可以自由**新增**自定义人格。自定义人格支持编辑与删除，删除当前人格时自动回退到第一个人格。

此外，在「人格库」中可开启「**启用默认 AstrBot 人格**」，使用 AstrBot 管理面板已配置的人格：可选择**跟随 AstrBot 配置文件当前人格**（自动使用 AstrBot 配置中当前采用的人格），或从 AstrBot 可用人格中选择一个；不使用 AstrBot 人格时，即使用插件人格库，也可随时在控制界面添加自己喜欢的人格。

## 💾 长期记忆

- 长期记忆以 **JSON 文件**形式存储于插件目录 `data/long_memory/`。
- **私聊记忆按用户分文件**：`user_<用户ID>.json`，仅该用户可见。
- **群聊记忆按群分文件**：`group_<群ID>.json`，记录该群内的对话记忆，不归属任何单个成员。
- 控制界面的「长期记忆管理」按「私聊记忆 / 群聊记忆」分组展示，支持：
  - **手动添加**：选择记忆类型（私聊/群聊）+ 填写用户ID/群ID + 记忆内容；
  - **逐条删除**：每条记忆均可单独删除；
  - **刷新记忆**：重新加载列表；
  - **清空全部**：一键清空所有记忆。
- 聊天指令 `/记忆列表`、`/删除记忆 序号`、`/清空长期记忆` 在私聊中操作自己的记忆，在群聊中操作当前群的记忆。

## ❤️ 好感度与私人陪护

- 好感度以 **JSON 文件**形式存储于插件目录 `data/favorability.json`，结构为 `{"user": {用户ID: 值}, "group": {群ID: 值}}`。
- **好感度面板开关**（`enable_favorability`）开启后，每次成功互动好感度 +1；AI 会在回复语气中自然体现当前好感度：低好感度保持礼貌克制、保持距离；中等自然友好；高好感度亲近热情。
- **起始好感度**（`favorability_default`）决定新用户/新群的初始值，范围 0-100，默认 50。
- 好感度面板提供管理功能：按「私聊 / 群聊」选择类型，填入用户/群 ID 可**查询**、**设置**指定好感度值，列表内每条记录可单独**调整 / 删除**，支持**刷新列表**与**清空全部**。
- **私人陪护**：开启后在面板中填写**主人用户 ID 列表**（仅私聊识别为主人，如 QQ 号，逗号分隔多个）。对主人，AI 以温柔贴心、百依百顺的私人陪护伙伴角色亲密回应；对非主人用户，若开启「**非主人避免过度言语亲密**」，AI 保持礼貌、克制与适当距离，不使用过于亲密、暧昧或撒娇的言语。
- 好感度与私人陪护相关配置均在「好感度面板」界面中修改，点击 **保存好感度设置** 生效。

## 🔒 安全提示

- **电脑权限默认关闭**。开启后 AI 仅能对**已授权用户**的对话中触发工具调用（管理员始终可用）。
- 工具执行带 30 秒超时、输出截断，请在可信环境使用。
- API Key 在控制界面以明文显示，请勿在公共环境中展示或分享屏幕。

## 📁 目录结构

```
astrbot_plugin_edge_tts/
├─ main.py            # 插件主逻辑
├─ metadata.yaml      # 插件元数据（显示名：Edge_TTS）
├─ _conf_schema.json  # 配置定义（全部 invisible，管理面板不显示）
├─ requirements.txt   # 依赖
├─ pages/
│  └─ dashboard/      # 控制界面
│     ├─ index.html
│     └─ app.js
└─ data/
   ├─ long_memory/    # 长期记忆文件（user_*.json / group_*.json，运行时自动生成）
   └─ <插件>_config.json   # 插件配置（持久化到 AstrBot 配置目录 data/config/）
```

> 插件配置统一持久化到 AstrBot 的 `data/config/astrbot_plugin_edge_tts_config.json`（或经典配置路径），由控制界面读写；人格库保存在插件 KV 存储中。
